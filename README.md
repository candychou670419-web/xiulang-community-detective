# 社區小偵探：尋找秀朗神祕守護者｜國小二年級實境解謎互動課程

本專案專為**國小二年級學生**設計，結合情境故事、平板互動網頁與實體社區四個站點（民權圖書館、得和派出所、瓦窯溝、民治市場），讓學童透過掃描 QR Code 體驗互動式解謎遊戲。

---

## 🎮 遊戲與教材產出檔案

1. **實境解謎互動網頁**：[`output/escape_room_game.html`](file:///g:/%E6%88%91%E7%9A%84%E9%9B%B2%E7%AB%AF%E7%A1%AC%E7%A2%9F/antigravity/123/output/escape_room_game.html)
   - 專為平板與手機觸控設計，支援雙體驗模式（QR Code 現場定點掃描 / 自由地圖切換）。
   - 內建語音朗讀（Web Speech API）、多感官音效與彩帶噴發動畫。
   - 包含【知、正、愛、合】四道關卡 puzzle 與終極數位榮譽證書下載。

2. **實體 QR Code 任務海報卡**：[`output/station_qr_cards.html`](file:///g:/%E6%88%91%E7%9A%84%E9%9B%B2%E7%AB%AF%E7%A1%AC%E7%A2%9F/antigravity/123/output/station_qr_cards.html)
   - A4 雙欄列印格式，包含 4 站 QR Code、實地小偵探任務提示與教師安全常規提醒。
   - 支援線上與本機部署網址一鍵切換與列印。

3. **QR Code 工具腳本**：[`output/generate_qr_cards.py`](file:///g:/%E6%88%91%E7%9A%84%E9%9B%B2%E7%AB%AF%E7%A1%AC%E7%A2%9F/antigravity/123/output/generate_qr_cards.py)

## 📚 四大站點遊戲設計對照表

| 節數 | 站點與主題 | 解謎任務與平板互動介面 | 學習目標與低年級設計重點 |
| --- | --- | --- | --- |
| **第一節** | **民權圖書館**<br>（文字解密） | **圖書密碼鎖**<br>依「`J 520 1234`」索書號找到書籍，於平板點選「知識就是力量」字詞組合解鎖【知】寶石。 | **目標：** 熟悉圖書館索書號使用。<br>**介面：** 大字體字塊選取、語音朗讀提示。 |
| **第二節** | **得和派出所**<br>（觀察辨識） | **波麗士眼力大考驗**<br>觀察派出所外警徽星芒數 (5顆) 與報案號碼 (110) 選答，解鎖【正】寶石。 | **目標：** 認識警察機關與求助管道。<br>**介面：** 圖像化單選題、大按鈕觸控。 |
| **第三節** | **瓦窯溝**<br>（生態探索） | **河畔生態 Bingo 卡**<br>3x3 九宮格觀察小白鷺、大公鵝、水質淨化設施等，點亮達成 2 條連線解鎖【愛】寶石。 | **目標：** 覺察社區生態與水資源保育。<br>**介面：** 翻牌動畫、Bingo 歡呼聲與連線驗證。 |
| **第四節** | **民治市場**<br>（金錢運用） | **30元美食探險家**<br>買 15 元紅豆餅與 10 元冬瓜茶，於平板點選拖曳硬幣組合 5 元找零金額，解鎖【合】寶石。 | **目標：** 體驗市場購物與面額加減。<br>**介面：** 擬真硬幣點算、動態找零錢包。 |
